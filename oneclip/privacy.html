개인정보처리방침

키쿠(kiku)가 개발한 원클립(com.kiku.oneclip)(이하 "앱")은 공유·메모 자동 분류 서비스로, 사용자의 개인정보를 소중히 여기며 개인정보 보호법 및 관련 법령을 준수합니다.

1. 수집·처리하는 정보

  • 사용자가 입력·공유한 텍스트, URL, 메모 (기본적으로 기기 내부 저장)
  • Google 계정 정보(이메일, 표시 이름, UID) — 클라우드 백업 사용 시에만
  • 앱 사용 통계 — 기기 내부에만 저장, 외부 전송 없음
  • OCR(카메라·갤러리) — 기기 내 ML Kit로 처리, 이미지는 외부 서버로 전송하지 않음

2. 정보 이용 목적

  • 메모 저장 및 AI 자동 분류·요약 (Google Gemini API)
  • 클라우드 백업 및 기기 간 동기화 (Firebase Firestore, 선택)
  • 망각 방지 리마인드 알림

3. 제3자 서비스

  • Google Firebase — 인증 및 데이터 저장 (클라우드 기능 사용 시)
  • Google Gemini API — AI 텍스트 분류 및 요약 (1회성 처리)

위 서비스 외 제3자에게 개인정보를 임의로 제공하지 않습니다. 본 앱은 AdMob 등 광고 SDK를 포함하지 않습니다.

4. 보관 기간

사용자가 데이터를 삭제하거나 앱을 삭제할 때까지 보관합니다.

5. 미성년자 보호

앱은 만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않습니다.

계정 및 클라우드 데이터 삭제

Google 로그인(클라우드 백업)을 사용한 경우, 아래 절차로 Firebase 계정·클라우드에 저장된 메모를 영구 삭제할 수 있습니다.

  1. 원클립 앱을 실행합니다.
  2. 설정 화면으로 이동합니다.
  3. 클라우드 백업 섹션에서 Google 로그인 상태를 확인합니다.
  4. 「계정·클라우드 데이터 삭제」 버튼을 탭합니다.
  5. 안내 확인 후 삭제를 선택합니다.
  6. 보안을 위해 Google 계정으로 재인증합니다.

삭제되는 데이터

  • Firebase Authentication 계정 (Google 연동 해제)
  • Firestore에 저장된 메모 및 사용자 프로필 문서

유지되는 데이터

  • 해당 기기에 저장된 로컬 메모 (의도적으로 유지)

계정 없이 데이터 삭제 (부분 삭제)

Google 계정을 삭제하지 않고도 아래 방법으로 데이터를 삭제할 수 있습니다.

메모 개별 삭제

  1. 원클립 앱 홈 또는 메모 상세 화면에서 삭제할 메모를 선택합니다.
  2. 삭제 기능으로 해당 메모를 제거합니다.

로컬 데이터 전체 삭제

  1. 기기 설정 → 앱 → 원클립 → 저장공간 삭제 또는
  2. 원클립 앱 삭제(제거)

클라우드만 삭제 (계정 포함)

Firebase에 동기화된 데이터만 삭제하려면 위 계정 및 클라우드 데이터 삭제 절차를 따르세요.

삭제되는 데이터

  • 선택한 메모 또는 기기 내 모든 로컬 메모
  • (계정 삭제 시) Firebase 클라우드 메모
