로또 AI 분석 개인정보처리방침

최종 수정일: 2026년 11월 17일 (앱 버전 1.8.17부터 적용)

1. 한눈에 보기

  • 회원가입·이름·전화번호·이메일을 받지 않습니다. 앱은 기기마다 익명 ID를 하나 만들어 씁니다.
  • 앱을 더 좋게 만들기 위해 앱 사용 통계(어떤 화면·기능을 썼는지, 다시 열었는지)를 Google Firebase 애널리틱스로 모읍니다. 번호·QR 내용·이름은 통계에 넣지 않습니다.
  • 무료로 운영하기 위해 Google AdMob 광고를 보여 줍니다. 광고에는 Google 정책에 따라 기기 광고 ID 등이 쓰입니다.
  • 정확한 위치(GPS), 연락처, 문자, 통화 기록은 수집하지 않습니다.

2. 수집·처리하는 정보와 목적

정보언제목적
익명 사용자 ID (Firebase 인증)앱을 처음 열 때 자동내 저장 번호·행운 포인트를 구분
생성한 번호와 방식, 스캔한 로또 용지 QR 주소, 행운 포인트번호를 만들거나 QR을 스캔할 때주간 통계·포인트 지급·같은 용지 중복 지급 방지
당첨 인증 사진·닉네임「명예의 전당」에 사용자가 직접 올릴 때만다른 사용자에게 인증 게시물로 보여 줌
앱 사용 통계: 앱 인스턴스 ID, 첫 실행·재방문, 기능 사용(분석번호 보기, 광고 보고 보상 받기, QR 확인 결과 등수, 주간 리포트 열기), 기기 종류·OS·앱 버전, IP에서 추정한 대략적인 지역앱을 쓰는 동안 자동 (Firebase 애널리틱스)어떤 기능이 쓸모 있는지, 다음 날·7일 뒤에도 다시 쓰는지 보고 앱을 고치기 위함
광고 정보: 광고 ID·앱 세트 ID, IP 주소, 광고 노출·클릭, 앱 성능 진단 정보광고가 나올 때 (Google AdMob)광고 제공·광고 성과 측정·부정 클릭 방지

애널리틱스에서는 광고 ID 수집과 광고 개인화 신호를 꺼 두었습니다. 통계는 광고 타기팅에 쓰지 않습니다.

저장한 번호 목록·메모·알림 설정은 기기 안에만 저장됩니다.

3. 제3자 서비스 (처리 위탁)

  • Google Firebase (인증·Firestore·Storage·애널리틱스) — Google LLC
  • Google AdMob (광고) — Google LLC

Google이 정보를 처리하는 방식: Google 개인정보처리방침, Google 파트너 사이트에서 데이터를 사용하는 방법. 전송되는 데이터는 TLS/HTTPS로 암호화됩니다. 위 서비스 외 제3자에게 개인정보를 팔거나 임의로 제공하지 않습니다.

4. 보관 기간

  • 번호·QR·포인트 기록: 삭제를 요청하거나 서비스를 끝낼 때까지
  • 애널리틱스 통계: Firebase(Google 애널리틱스)의 데이터 보관 기간 설정에 따름
  • 광고 데이터: Google 정책에 따름

5. 내 정보 지우기·거부하기

  • 기기 안 데이터: 기기 설정 → 애플리케이션 → 로또 AI → 저장공간 → 데이터 삭제, 또는 앱 삭제.
  • 서버에 저장된 번호·QR·포인트·인증 게시물: 아래 이메일로 요청하면 확인 후 지웁니다. (요청 날짜와 대략적인 사용 기간을 함께 보내 주세요.)
  • 맞춤 광고 끄기: 기기 설정 → Google → 광고 → 광고 ID 삭제.

6. 아동

로또는 만 19세 이상만 살 수 있습니다. 앱은 만 14세 미만 아동의 정보를 일부러 수집하지 않습니다.
